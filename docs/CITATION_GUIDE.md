# How to cite RSOS

**Repository:** https://github.com/r-a-elu-architecture/RSOS-Multimodal-Cue-Framework

**Citation metadata:** [CITATION.cff](../CITATION.cff). GitHub shows a "Cite this repository" button built from it.

**Current version:** v2.0.0. Zenodo assigns a DOI to each GitHub release; once the v2.0.0 DOI exists it is added to `CITATION.cff` and the README.

**Earlier version:** v1.0.0-research-preview, [doi:10.5281/zenodo.24143732](https://doi.org/10.5281/zenodo.24143732) (superseded).

## What to cite

- **The Override Protocol:** the specification, `spec/OVERRIDE_PROTOCOL.md`, with the version number in its header.
- **RSX, the player or the cue engine:** the software release and its DOI.
- **Model predictions:** `rsx/model/PREDICTIONS.md`, with the release version.
- **Historical records:** the archive path and SHA-256 from the [source manifest](../archive/provenance/SOURCE-MANIFEST.csv).
