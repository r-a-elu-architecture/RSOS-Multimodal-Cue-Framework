# RSOS Research Framework — Research Preview v1.0.0

**Status:** GitHub research preview released November 11, 2026; archived at Zenodo version DOI [10.5281/zenodo.24143732](https://doi.org/10.5281/zenodo.24143732).

## Scope

This research preview makes the RSOS–RSIA–RSX–RSSO framework publicly inspectable, with executable software, source archives, cross-system architecture documentation, benchmark evidence and methods drafts.

### Research components
- **RSOS:** personal symbolic/cue representations, optional tier ranges, glyph meanings, mnemonic associations.
- **RSIA:** uncertainty, permission and assumption checks, evidence-based abstention and fallback.
- **RSX:** typed configurable cue/operator programs.
- **RSSO:** calibration, historical context, orchestration and provenance.
- **Runnable v1.3 benchmark:** `experiments/compositional-transfer-v1.3/`.
- **Historical archives:** immutable original ZIP, 65 extracted source files, source SHA-256s and archive/navigation index.

## Reproduction

From the repository root:

```bash
cd experiments/compositional-transfer-v1.3
python -m pip install -r requirements.txt
bash run_all.sh
```

A shorter local run is available via `bash run_smoke.sh`. The workflow `.github/workflows/manual-reproduction.yml` is manual-only; it has not been run on GitHub as part of preparing this release.

## Measured computational results (synthetic)

In the v1.3 simulated cohort, evidence-gated relation-aware control reported mean decision regret **0.1978** versus **0.2267** for a generic all-pairs baseline (12.7% lower regret). A generic cross-validation selector reported **0.1951** and an equally informed generic evidence-gate controller matched **0.1978**. A separate withheld-context synthetic comparison reported **0.1985** versus **0.2169** for all-pairs.

**Limitations:** The preference-generating processes are simulated. No clinical efficacy, durable conditioning, EEG identification of emotions, or unprecedented neurological mechanism is demonstrated. See `research/compositional-transfer-v1.3/RESULTS_REPORT.md` and `docs/BENCHMARKS.md`.
