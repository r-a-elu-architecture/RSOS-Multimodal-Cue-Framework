Mission / experiment contract

When should an adaptive system transfer a learned cue relationship—and when should it refuse?

This lab tests a narrower RSOS hypothesis: whether relationships among simulated glyph, sound and program choices can be reused across contexts with less error than equally informed alternatives. Its aim is to detect both useful transfer and negative transfer, not to prove that RSOS is inherently superior.

Research goal

Compare evidence-gated compositional selection, personal-memory and generic learning policies using identical candidate actions, calibration observations and simulated reward functions. Identify the environments where a relationship gate helps or hurts.

Success criterion

A reproducible, statistically defensible reduction in regret against the strongest non-identical, equally informed generic comparators on predeclared independent seeds and worlds. Real conditioning claims require separate consenting-human outcome studies.

Falsification and strongest rivals

The generic controller using precisely the same model and gate must tie. A generic 3-fold CV selector is allowed to win. The frozen full holdout shows that CV did achieve lower synthetic regret than RSIA (0.195136 versus 0.197825).

What visitors are actually running

The unchanged archived v1.3 Python source executes in-browser against artificially generated outcomes. The smaller live sample is not the frozen multi-seed reference, an external replication, or a measure of human learning, EEG or therapy.

How it fits RSOS: Cue Lab is an application-level transfer experiment. The separate Architecture Benchmark Lab investigates historical dialogue structure and provenance. Read the shared mission, current evidence and next tests.

What the evidence gate actually does

The original code estimates between-family explained variance, eta = SS_between / SS_total, using the simulated person's 24 calibration observations. When eta ≥ threshold, it selects a cue-family relational predictor; otherwise it falls back to per-person flat cue memory. The generic same-gate controller performs the identical operation, intentionally producing an exact tie. The generic CV selector instead compares the relational and flat model on three calibration folds.

Why a smaller live run can disagree with the frozen table

The frozen holdout includes three seeds and 48 persons in every simulated world; the live browser runs one chosen seed and at most 12 persons per world. World mixtures, sample sizes, threshold settings, and balanced design alter mean regret. Single-run results carry no independent scientific inference or new significance claim.
