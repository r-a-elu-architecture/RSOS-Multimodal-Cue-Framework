# Benchmarks and evidence register

**Read this before quoting any number.** The results below evaluate *software decisions or artificial response-generating worlds*, not human emotional recovery.

| Track | Measured finding | Limit |
|---|---|---|
| Compositional cue transfer v1.3 | Synthetic regret 0.1978 vs generic all-pairs 0.2267 (12.7% relative reduction); unseen context 0.1985 vs 0.2169 | Equally informed generic evidence-gated model matched exactly; generic cross-validation selector competitive |
| Functional-operator representation v1.0 | Conversation-held-out macro average precision 0.5547 vs context-aware text baseline 0.4804; Brier 0.1492 vs 0.1637 | Predicts subsequent protocol **language**, not neurological response |
| Provenance v0.7 | Invalid targeted requests rejected in synthetic security cases on a real-message ancestry graph | Generic graph-proof controller matched exactly |
| Privacy-preserving adaptation v0.8 | Real-corpus aggregate tests of body-free ancestry certificates and signed authorization | No external audit or human outcomes |
| Ancestry attestation v0.9 | Approx. 7.6–7.8× smaller proof than project's v0.8 internal implementation | Slower initial verification and additional auditor trust; not compared against strongest optimized third-party structures |
| BCI routing v0.6 | Two-sensor simulated risk-proxy reduction vs one-sensor controller | Matched generic two-sensor controller tied; correlated noise weakened benefit |
| Factorial cue simulation v1.1 | Adaptive combination choice reduced artificial regret vs fixed routines | Generic pairwise model competitive; intervention effects invented |
| Programmable cue interface v1.2 | Personalized programs beat fixed programs in simulated calibration worlds | Generic hierarchical approach competitive; no real personalized conditioning |

**Publication status:** draft manuscripts, executable research prototypes, prior synthetic runs; no peer-reviewed clinical paper or randomized clinical outcomes.

Numerical claims must specify units, seeds, task definition, and negative results. See [flagship report](../research/compositional-transfer-v1.3/RESULTS_REPORT.md), [flagship draft](../research/compositional-transfer-v1.3/PREPRINT_DRAFT.md), and [study protocol](../research/compositional-transfer-v1.3/NEXT_HUMAN_STUDY.md).

**Reproducibility notice:** Not every historical benchmark's complete raw files are included in the first GitHub documentation release. A claim is not independently reproduced from this repository until its versioned source, seeds, and data-generation commands are available here and actually run by a separate party.
