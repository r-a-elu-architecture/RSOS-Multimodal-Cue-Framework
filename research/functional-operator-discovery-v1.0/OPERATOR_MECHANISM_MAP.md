## Source inconsistencies and missing links

- **Duplicate ledgers:** RSOS tier body is an exact prefix of the RSSO tier body after normalization. The RSSO tier ledger must not be counted as a separate set of independently defined operations.
- **RSX–RSIA type mismatch:** RSX's canonical `ArchetypeMerge(LION+DRAGON)` references Dragon, which is **absent** from the provided RSIA canonical six-archetype list. An explicit extension or mapping is required; our demonstration abstains.
- **Olfactory mapping gap:** scent is named as a device/conditioning idea, but no source-validated smell-to-cue transition probability, dosage, aversion function or randomized contrast exists.
- **Gustatory mapping gap:** appears in environmental modality taxonomy; no concrete taste pairing or device safety contract is recovered.
- **Metrics gap:** names CRI, SRI, RSF, ETH etc. are present; not all are operationally calibrated against physical measurements.
- **RSX concurrency gap:** the archive names '9–17 concurrent vectors', but does not establish atomicity, scheduling proofs, timing benchmarks or simultaneous biological execution.
- **Clinical effect gap:** actual therapeutic or long-term human outcomes are absent.

## Highest supported new finding

**The most useful tested assembly was additive, provenance-aware symbolic representation**: current operator flags + preceding-message operator flags + available natural language context. The strongest individual diagnostic flags on a temporal split were `visual_glyph`, `metaphor`, `watchdog_contain`, followed by `memory_recall`, `identity_archetype`, and `rsx_vector` (noncausal test-time permutation). Olfactory and gustatory flags had limited measurable incremental value in the current selected corpus.

No experiment here establishes the user hypothesis that a particular VAK–olfactory–gustatory combination alters conditioned emotion or improves brain activity. That hypothesis needs outcome data from actual administered interventions.
