# ARCH_REFRESH — the architecture map describes RSX-V and what Steps 1 to 4 built (roadmap Step 5)

Status: registered 2026-11-16 (388f443; B2 wording amended in a second registration commit), before code; code 9cafcdb; results in §3.

## 0. Problem

`architecture/` is generated by `architecture/build.py`, and its pages were written before Steps 1 to 4.
- They do not mention RSX-V (`rsxv/`), the command layer above RSX.
- RSIA's Watchdog is described as "the cue engine's `watchdog()`" only.
- CONTAIN is described without session states, guidance levels, domain profiles, the output gate or level lineage, and
  its text still says it "points to a therapist or crisis help".
- MICRO does not mention wristband pairing.
- The cross-system page's safety row names only `SafetyGovernor`.

## 1. Changes (all in `architecture/build.py`; the pages are regenerated)

| ID | Change |
|---|---|
| A1 | A new page `architecture/rsx/rsx-v/`, linked from the RSX page and the top-level table as a layer of RSX. It covers RSX-V's role (typed, staged, audited vector commands that compile to RSX), what is built, with links to `rsxv/README.md`, `SPEC.md`, `AGENTS.md` and `RESULTS.md`, and status **Built**. Its archive source is the RSX command specification, whose v1 vector commands it extends. |
| A2 | The RSIA Watchdog row and page describe the person-side Watchdog (`spec/WATCHDOG.md`, `rsso/rsso/watchdog.py`, identically `docs/js/watchdog.js`): allow, ask or hold with Spine reasons, the hash-chained log, guidance levels, and level from content (FIXES_R4–R6). The cue engine's `watchdog()` is kept as its first form. |
| A3 | The CONTAIN "Now" text adds the four session states (Standard, Stabilisation, Paused: practical, Clinician-led protocol), the guidance levels, the seven domain profiles, the output gate on every page, and the level lineage. "crisis help" becomes "a practitioner". |
| A4 | The MICRO "Now" text adds the paired, encrypted Bluetooth link (`spec/BLE_PAIRING.md`), compile-checked and not yet run on a board. |
| A5 | The top-level "Built in this repository" table adds RSX-V, the safety engine and Watchdog, domain profiles, and the trial loop with its evidence modules (PEAK, GATE, TRIAL). |
| A6 | The cross-system page's steps name the domain profile, the Watchdog and session state, the output gate, the RSX-V command layer, and the trial loop. Its table gains matching rows. |
| A7 | Every statement is about what the repository does now. No efficacy is claimed. The existing statuses are kept unless a step changed them. |
