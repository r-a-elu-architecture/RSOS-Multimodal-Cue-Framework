## 2. The fused agent system (the organism)

AGENTS_ANCHOR found that switching helps agents (Watchdog beats always Bear by +0.0155) and costs persons (always Bear
beats the Watchdog). The organism fuses the measured best of each side, and replaces live exploration on persons with
replay:

- **Person side:** the anchored rule (Bear unless the ledger's interval rules Bear out) with **no live exploration**;
  its ledger starts from **replayed** runs of 50 other persons (seeds 281000–281049, Watchdog policy, model v3), so it
  learns without trying modes on the person.
- **Agent side:** the Watchdog, unchanged.

**What the map shows.**
1. **186 of 293 tiers carry no response**: no agent role can execute them yet. They are the largest unbuilt reserve.
2. **The metrics do not tell the roles apart.** The same four codes (CRI, LGC, RSF, SAR) lead on every role: the
   ledger measured every tier with the same instruments. An organism needs a sensor per role; the ledger has none yet.
3. **Echo is concentrated in Epoch IV** (144 of 152 tiers name it; 287 of the 409 Echo-family values), and 81% of the
   Echo-family values sit on tiers no role executes.
4. **Baseline (Lion) has 0 built tiers**, although it is the Watchdog's default start.
