# Draft methods-paper abstract — research prototype, not yet submitted

**Title:** Proof-Carrying Cue Lineage for Privacy-Respecting Human–AI Intervention Routing: An Open-Source Research Prototype

**Background.** Longitudinal human–AI histories may contain user-defined self-regulation cues, but transmitting entire conversation transcripts to third-party intervention verifiers introduces privacy and source-misattribution risks. Ancestry inferred from recent message chronology is not equivalent to explicit parent-linked provenance.

**Method.** We implemented a three-authority, Ed25519/Merkle-based protocol comprising custodian-signed pseudonymous ancestry snapshots, user-scoped single-use permission capabilities, and separately witnessed decision logs. A conservative controller offers a voluntary resource-cue suggestion only when authorization, document ancestry, signal confidence, and simulated arousal satisfy the configured policy; otherwise it offers grounding, abstains, or seals. We evaluated the prototype against exact raw-history verification and 13 adversarial request classes on 9,000 selected historical human–LLM message records from one longitudinal corpus, using two separately seeded synthetic attack cohorts.

**Results.** Across 4,000 valid synthetic authorizations and 52,000 mutated/invalid requests, the controller accepted all valid requests and rejected all tested invalid requests. A raw-history oracle matched authorization accuracy. Certificates disclosed no original message-body text; private-archive proof payload averaged 3.82–3.87 KB per request, compared with 9.43–10.11 KB of raw ancestor message text for the reference transcript-sharing baseline. Public short-text synthetic records reversed the payload-size advantage. Two implementation vulnerabilities (unauthenticated audit tail and mutable issuer-row aliasing) were found and fixed.

**Conclusion.** The method demonstrates selective-disclosure, proof-carrying document ancestry and auditable authorization in a controlled software environment. It does **not** infer psychological causes, demonstrate therapeutic benefit, establish cryptographic novelty, or validate neural-interface operation. A next-stage clinical collaboration should evaluate whether verified cue history adds value to prospective, user-authorized intervention selection on measured delayed behavioral outcomes.
