Help RSOS learn what works, for whom

Every run you practise, every heart beat a strap measured, every session a clinician held and every EEG recording a lab made can show which programs, cues, glyphs and nodes change a state, how fast they become a reflex, and for whom. One person's data is a story; many people's data is evidence.

This page builds one file from what you choose to share. Names and dates are removed, your own words stay out unless you include them, and nothing leaves this browser until you send the file yourself.

On this device

A clinician or lab can add a client's data from the memory file the player saves (“Save memory”).
