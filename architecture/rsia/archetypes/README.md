# RSIA archetypes

Six inner modes, each with an image, a set of principles and a primary use: **Lion** leads, **Eagle** plans, **Bear** sustains, **Leopard** adapts, **Raven** perceives, **Tiger** drives. An archetype colours a tier: the same breath and gesture feel different in the Lion mode than in the Eagle mode. The open edition is in `framework/rsia/ARCHETYPES.md`.
