# UGCL glyph library build

- Population evolved by mutation from seed glyphs: 600 glyphs, each with its parent and mutation recorded.
- Selected for maximal mutual distinctness: 48 glyphs (G01–G48).
- Smallest visual distance between any two selected glyphs: 0.0324 (a random set of the same size: 0.0000).
- Distinct haptic rhythms among the selected: 45 of 48; distinct tone motifs: 38 of 48.
- Archetype glyphs come from the tier ledger (the original glyphs, `docs/ugcl/originals.json`); this generated set is an optional extra.

Visual distance is the symmetric chamfer distance between 64×64 renderings, as a fraction of the image width.
