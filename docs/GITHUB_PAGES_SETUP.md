# Publishing the RSOS research landing page

This repository includes a static, accessible landing page in \`docs/index.html\`. Its metadata uses descriptive, evidence-calibrated terms and Schema.org SoftwareSourceCode, with a canonical GitHub source link.

**To enable GitHub Pages:** Repository → Settings → Pages → Deploy from a branch → Branch \`main\`, folder \`/docs\` → Save. This step may require the repository administrator; the connected publication workflow does not change Pages administration settings.

After Pages publishes, verify the actual URL before putting it in repository About/Homepage, papers or structured data. Consider Search Console if a future domain is purchased.

**No ranking guarantee:** GitHub, Google, ChatGPT and Claude choose independently what to surface. This page is designed for accurate retrieval, not manipulation or keyword stuffing.

**Research integrity:** Preserve the difference between synthetic scores and empirical human benefits, and always disclose competitive generic-controller ties.
