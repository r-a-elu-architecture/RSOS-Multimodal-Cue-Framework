# Published experimental comparisons

This directory contains **exact, unrounded comparison CSVs** copied from the local v1.3 open-science release. All participant preferences and outcomes in this benchmark were generated by software. They are **not** recorded physiological, clinical, or human behavioral responses.

## Tables

- [Independent three-seed holdout](holdout_comparisons.csv): paired synthetic-regret contrasts from the 24 seed-by-world clusters (seeds 63011–63013).
- [Unseen-context holdout](unseen_context_comparisons.csv): paired synthetic-regret contrasts with a deliberately withheld calibration context (seeds 64011–64013).

### Interpreting the numbers

`mean_regret_improvement` is regret for the comparator **minus** regret for `rsia_evidence_gate`. Positive values favor the evidence-gated method. `ci_low` and `ci_high` are participant/world-cluster bootstrap intervals reported by the original code.

**Important adverse control:** `generic_same_gate` has exactly the same values as the RSOS-inspired evidence gate. A separate generic cross-validation selector is statistically competitive. This is not evidence of uniquely superior neural or conditioning mechanisms.

## Reproduce on your own machine

From the repository root:

```bash
cd experiments/compositional-transfer-v1.3
python -m pip install -r requirements.txt
bash run_all.sh
```

The benchmark writes the full per-seed, per-world, bootstrap and heldout-trial outputs under its `results/` folder. Trial-level CSVs (which can be large) are regenerated rather than committed. See [BENCHMARK_MANIFEST.json](../BENCHMARK_MANIFEST.json), [REPRODUCIBILITY.md](../REPRODUCIBILITY.md) and [the paper draft](../../../research/compositional-transfer-v1.3/PREPRINT_DRAFT.md).

The optional GitHub workflow in `.github/workflows/manual-reproduction.yml` is manually dispatched and is not configured to trigger background billing or execution automatically.
