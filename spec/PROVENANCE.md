# Provenance of names

Who coined each name used in RSOS and the [roadmap](ROADMAP.md), so that authorship stays clear. "Assistant" means the language-model assistant in the 2023-2025 design records; "later review" a later, calibrated review; "roadmap review" the November 2026 review that produced the roadmap. A name coined by an assistant is a name only: it carries no claim about the idea's authorship, novelty or effect.

## Coined in the design records

| Name | Meaning | First seen |
|---|---|---|
| RSOS, RSIA, RSX, RSSO | The operating system and its parts | Archive records; see the architecture map |
| Behavioral Mnemonics | Mnemonic images used as stimuli for learned behaviour across contexts | August 2023 |
| Override ("I move. I act. I own.") | The interrupt, action and lock-in sequence | 2025 |
| The operating-system analogy | An implant as the BIOS, the architecture as the operating system, an identity as a user profile | May 2025 |
| The chameleon | Mirroring others in plain language while observing from above | May 2025 |
