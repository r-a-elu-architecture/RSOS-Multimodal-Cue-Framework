How the illustrative policy works

Confidence = consistency × [observations / (observations + 4)] × context similarity × composition penalty. Similarity factors: familiar 1.00, shifted 0.85, novel 0.60. Composition penalty = 1 − 0.04 × (channels − 1). The controller transfers only if confidence meets the threshold; otherwise it requests evidence or falls back. These coefficients are explicitly illustrative, not fitted to human data.

3 · Compare policies on the same synthetic cases

Run a deterministic seeded simulation. Both policies receive identical synthetic cases. The comparison is a teaching example and cannot establish superiority over an optimized, equally informed controller.

Run the simulation to view results.

Simulation specification and limitations

A seeded generator samples context, cue count, observation count and consistency. The latent synthetic success probability is constructed from those features; a fixed random draw creates an outcome. The evidence-gated policy transfers only when its illustrative confidence exceeds the selected threshold. The always-transfer baseline transfers in every case. For each case, the simulated loss is 1 for transferring when the generated outcome is failure, 0 for transferring when it is success, and 0.30 for abstaining. Mean loss is reported; lower is better. The generator and controller share design assumptions, so results are not independent validation. Changing assumptions or abstention cost can reverse the ranking. This is not the archived v1.3 benchmark.
