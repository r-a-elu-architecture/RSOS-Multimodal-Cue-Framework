# Research discovery and citation strategy

## Canonical identity

**Project:** RSOS — Multimodal Cue & Adaptive Human–AI Research Framework.
**GitHub:** https://github.com/r-a-elu-architecture/RSOS-Multimodal-Cue-Framework

Suggested discovery concepts: programmable multimodal cue systems, personalized mnemonic glyphs, adaptive human–AI interfaces, evidence-gated compositional transfer, context-aware learning, EEG/BCI research, privacy-preserving cue provenance and configurable behavioral rehearsal.

## Discovery hierarchy

1. Repository About description and **relevant** GitHub topics
2. Main README: exact capabilities, evidence boundaries, and navigation
3. Dedicated topical pages in `docs/` (descriptive headings and cross-links)
4. Versioned research drafts, runnable implementations, structured benchmark results
5. Stable release and citation metadata only **after** tagged publication
6. Independent citations, forks, reproductions and responsible technical articles

There is no way to force ChatGPT, Claude or other search products to recommend a given repository. Credibility requires results that genuinely answer users' questions.

## Measurement

The `research/discovery-query-matrix.csv` lists 31 candidate branded and unbranded searches. Evaluate presence, accurate attribution, correct deep link, evidence calibration and genuine user interest. Do not invent SEO performance or buy artificial citations.

## Publication

Add a scoped software license before claiming legally open source. A citable Zenodo DOI should be added only when actually minted. Original copyrighted estates require separate publication decisions.
