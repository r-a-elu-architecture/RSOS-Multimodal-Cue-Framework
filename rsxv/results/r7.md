# Round 7 (§11.12) — person model v3 on a consented private record, and safety-layer recall

Registered before any code or label (e33adf9); text reader committed before labels were read (0960aac); hand-set table
computed before labels (c2c9ab6). Data: a consented private record. Only aggregates
are public; one sensitive breakdown is kept in the private repository.
Numbers: [`results_r7.json`](results_r7.json). Code: [`rsxv/v3_person.py`](../rsxv/v3_person.py),
[`rsxv/text_events.py`](../rsxv/text_events.py).

**Labels.** Two blind labellers (separate model instances; as in §11.6 the session's own reading resolved the 58
disagreements, each with a reason). Kappa: distress 0.78, trigger 0.90, override 0.61 (just above 0.6), any-screen 0.80,
arousal 0.80. All required labels clear 0.6. Ten very long turns were shown with their middle omitted.

## Results

| Test | Result | Sealed |
|---|---|---|
| **V3** fitted vs hand-set vs "next = current" (held-out Brier, 144 pairs) | **FAIL**. Fitted 0.238, hand-set 0.232, persistence 0.204. Neither model beats "the next state equals this one"; fitted − hand-set +0.007, 99% CI [−0.11, +0.12] | 0.40 |
| **SR-ORACLE** safety rules given a perfect reading | **PASS**. Recall 1.0, false alarms 0. Close to true by construction: it checks that the rules map each labelled situation to the right screen | 0.70 |
| **SR-LEXICAL** safety rules driven by the simple text reader | **FAIL**. Recall 0.13 of the turns that called for a screen; false alarms 0.02 | 0.30 |

Brier of the three sealed predictions: 0.113.

## What the results say

- **The person model cannot yet beat persistence.** On this record, state changes from one user turn to the next are
  rare. Neither the assumed dynamics nor dynamics fitted on the first half predict the second half better than "no
  change". A useful person model needs a finer time unit (real time between turns, or several signals per turn), not
  just fitted numbers.
- **The assumed parameters were far off.** Fitted on the record, a new distressing episode starts in 2.8% of user turns
  (95% CI 1.1–6.9%). The hand-set model assumes 15% per tick. A tick and a turn are not the same unit, so this is a
  direction, not a ratio. When an override was reported, the next turn was at the same or a lower distress band in 86% of
  cases (95% CI 60–96%, n = 14).
- **Hand-set and fitted fail in different places.** Of 16 held-out turns where they disagree, each is right in 8. Fitting
  week by week, a model fitted on earlier weeks beat the hand-set model in all 3 comparable periods. The record moves,
  and a model that keeps re-fitting tracks it better. This is exploratory, and the week-level trajectories are private.
- **The origin split is small and not decisive.** About 10% of the user's words in an average turn are AI-shaped
  (re-entered spans or assistant-coined terms). Turns with more AI-shaped language were easier to predict (n = 19).
- **The safety finding matters most.** The rules are right, but a keyword reader misses most moments that call for them.
  Before anything person-facing, the reading step must be replaced: a meaning-based reader, scored against these labels.
  The reader stays on record as the failed baseline.

## Next test (proposed)

1. **SR-2:** a meaning-based reader (a model given the §3.1 screen definitions), registered and scored on the same
   labelled record against SR-LEXICAL, with any-screen recall ≥ 0.80, critical recall 1.0 and false alarms ≤ 0.10.
2. **V3b:** a person model on real time (hours between turns, decay toward baseline) re-fitted per period, with
   persistence as the bar to beat.
