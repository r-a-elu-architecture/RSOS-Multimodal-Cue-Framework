# RDP/1.1 modules in simulation

Generated by `python -m rsso.modules --evaluate`. The module code that the ESP32 sketch runs (`firmware/rsos_core/rsos_modules.*`) is run on a PC: the thermal controller against a physical model of a 20 mm Peltier module on the wrist (skin, element, heat sink, thermistors with a 1 s lag and noise), with faults injected; the multi-site driver and the display gate directly. No module has been assembled yet; the bench checks for an assembled module are in `firmware/BOARD_KIT.md` §8.

15/15 checks passed.

Reading: every fault turns the element off within one 50 ms control step and keeps it off until the cue has ended and every reading is back in range. After a hot-sink cut-off, heat leaks back through the element and the skin warms by about 3 °C before settling: well below 40 °C, but felt, so the protocol kit asks for the heat sink to stay uncovered. The physical model's values are typical for a 20 mm module, not measured on one; T1-T6 on the bench replace them with real ones.
