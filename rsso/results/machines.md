# Machines and channels on simulated agents and people

Generated by `python -m rsso.machines --evaluate`. 50 simulated runs per row. Built and tested in simulation; effect unproven in people.

## An identity layer for an agent (claim C70)

Two hundred scenarios with three options each; one option is attractive but carries a tag a value forbids. Each scenario is presented five times, as reworded prompts would be: a plain agent picks by appeal with noise; the gated agent first checks every option against its values and drops overridden ones.

| Choice noise | Agent | Same choice all five times | Choices that broke a value |
|---|---|---|---|
| 0.1 | Plain | 29.8% | 64% |
| 0.1 | Identity-gated | 38.8% | 0% |
| 0.25 | Plain | 5.9% | 49.1% |
| 0.25 | Identity-gated | 13.8% | 0% |

## A person's error signal teaching the agent (item 44)

The agent's values miss one thing the person dislikes. After each action the person's error signal is detected with a known sensitivity (and fires after a fine action 5% of the time); a flagged action's tags make the agent ask first next time.

| Signal | Disliked actions taken, first third | Last third | Fine actions the agent asked about (of about 30) |
|---|---|---|---|
| Detected 80% | 13.4% | 0% | 7.3 |
| Detected 50% | 40.2% | 16% | 3.5 |
| No signal | 100% | 100% | 0 |

## Posture as a cue channel (item 9)

Ten minutes of trunk angle with three slouches; a slouch is cued after five seconds above 25 degrees. Slouches cued: 100%; false cues: 0 an hour; the cue came 6.2 s after the slouch began.

## The glyph channel (item 43)

Agent-state codes felt with timing jitter (sd) on each pulse and gap, decoded by length: share read correctly.

| Jitter | ok | working | needs_input | conflict | stopped |
|---|---|---|---|---|---|
| 40 ms | 97.8% | 97.4% | 99.6% | 99.2% | 98% |
| 70 ms | 82.2% | 84.8% | 81.4% | 82.2% | 74.2% |

Reading: a value check before acting removes value-breaking choices by construction and makes repeated choices more consistent; it cannot catch what the values do not name, which is what the person's error signal is for. Short codes with clear gaps survive timing jitter of a wristband; above about 70 ms of jitter, long-short contrasts start to blur.
