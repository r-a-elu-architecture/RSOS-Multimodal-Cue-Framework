# Synthetic 4-week study (40 virtual participants, assumed effects)

3302 runs from 40 participants.

## H2 — practice: faster and more automatic

- Log-latency slope per run: -0.03 (95% CI -0.03 to -0.03), d_z = -3.07, p = 1.2e-21, n = 40 (about 3.0% faster per run)
- Median latency, first 5 runs → last 5 runs: 61.8 s → 9.6 s
- Automaticity (SRBAI), week 1 → week 4: +1.65 points (95% CI +1.48 to +1.83), d_z = 2.97, p = 3.9e-21, n = 40

## H5 — device triggering vs self-initiated only

- Share of triggers followed by a run: device arm 92% vs self-only 71% (p = 6.7e-12, n = 20 + 20)
- Median latency: device arm 19.6 s vs self-only 34.1 s (p = 0.00043)
