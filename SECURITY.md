# Security and safety

RSOS is **research software**, not a regulated medical product. Report security or privacy issues privately to the repository maintainers rather than disclosing exploit details in a public issue.

Core concerns: consent spoofing, stale or revoked authorization, cross-user glyph binding, forged ancestry proofs, shared-sensor artifacts, miscalibrated context inference, unverifiable logs, and improper automatic stimulus delivery.

Software-level safety controls do not guarantee absence of psychological harm. Any real-person conditioning or mental-health experiment requires appropriate informed consent and qualified ethical oversight.

Never commit credentials, raw personal conversation archives, identifiable physiological recordings or third-party records without documented rights and permission.
