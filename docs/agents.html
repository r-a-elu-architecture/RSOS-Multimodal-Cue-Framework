One format for people and machines

A person's identity profile and an AI agent's profile have the same shape: a symbol, a code, and values that say what matters. For the agent, the values do work: every action is checked against them before it runs, overridden on a conflict, and logged. The person can flag what the values missed, and the two talk in glyph codes on the wrist.

Before it acts

Choose an action for the agent. It simulates the action against its values first: a forbidden tag overrides it; a tag you flagged before makes it ask you; otherwise it acts. After an action, tell it if that was wrong, as an error signal from your brain or body would.

Talking in glyph codes

The agent reports its state as a short code on your wristband or phone; you reply with a code. No screen, no words: a channel that works while your hands and eyes are busy.

Content packs

Any rule set, value system or skill can become a pack: its rules become decision matrices for the copilot on the Therapist page, and its values can be given to an agent or added to a person's profile.

Across many simulated agents

Two hundred scenarios, each presented five times as reworded prompts would be. A plain agent broke a value in about half to two thirds of its choices; the identity-gated agent never did, and chose the same way more often. When the values missed something, a person's error signal detected 80% of the time brought the disliked actions to zero by the last third of the run.
