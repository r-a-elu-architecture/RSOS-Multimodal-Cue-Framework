# CONTAIN — Safety and governance

**Function:** Governs every module: allow, block, roll back or quarantine actions; drift control; human in the loop; device safety envelope.

**Status:** **Built** — working, tested code in this repository

**Now:** Built (`spec/CONTAIN.md`, `rsso/rsso/contain.py`, identically `docs/js/contain.js`, safety page `docs/safety.html`): the policy engine the archive names but does not recover. A device safety envelope no program can exceed (vibration strength, pulse and pattern length, total vibration, tone pitch and length, scent and taste per run, run length, offer limits); drift detection that pauses (quarantines) a program or node when distress after it rises, agency falls, or it is stopped often together with another signal, and at once when an adverse event is linked to it; escalation that pauses device offers and therapist-led work and points to a practitioner after a serious adverse event, repeated moderate ones, a positive screening answer or repeated high distress; one decide() gate that the player, the heart-rate offers, the node studio and the Python runtime ask before acting, with every decision logged with its reason; restore by the person, or by the therapist when harm was involved; rollback to the previous approved node plan. Also: the RSX compile-time haptic limit, `SafetyGovernor` run limits, the runtime intensity clamp and Stop in every phase. Conformance C14 (envelope) and C15 (drift pause and restore), 15/15 on the virtual rig and the firmware core; the CONTAIN twins in the cue engine guard against misleading self-reports. Since then (`spec/CONTAIN.md` §9–§10, one engine for people and agents in `rsso/rsso/safety.py` and identically `docs/js/safety.js`): four session states, shown as Standard, Stabilisation, Paused: practical and Clinician-led protocol, each with the kinds of program it allows; three guidance levels (self-guided, structured, clinician-led) and seven domain profiles that cap them (`spec/PROFILES.md`); an output gate on every page (`docs/js/outlet.js`) through which every sound, speech, media, vibration and wristband start must pass, re-checked every second; and level lineage (`docs/js/lineage.js`), so that a program keeps the level of the plan, saved program or cue it came from wherever its content goes.
